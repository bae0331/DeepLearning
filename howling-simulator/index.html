🩺 진단 및 권장 사항

    ✨ 자동 최적 배치

    스피커와 앰프는 항상 벽에 붙여 배치합니다(벽에서 약 20 cm). 보컬은 멤버들을 바라보는 방향으로, 다른 멤버·스피커와 겹치지 않게 배치합니다.

    🟩 흡음재 추천 어떤 흡음재를 · 어느 벽 어디에 · 얼마나

    이미 붙인 흡음재와 지금 보이는 추천은 그대로 두고, 입력한 면적만큼 그다음으로 효과가 큰 위치에 흡음재를 더합니다. 여러 번 누를 수 있습니다.

    현재 스피커·마이크 배치에서 하울링 여유와 합주실 적정 잔향시간(0.3–0.45초)을 가장 효율적으로 개선하는 흡음재를 단계적으로 고릅니다. 배치를 먼저 최적화한 뒤 실행하면 더 정확합니다.

    📐 계산 방법

    루프 게인 = 전기적 게인(정격 W·감도·볼륨 노브·믹서 게인) + 실내 전달(스피커 → 마이크). 어떤 주파수에서든 0 dB 이상이면 하울링이 발생합니다. 보통 6 dB 이상의 여유를 둡니다.

    보컬 신호 출력: 기타·베이스 앰프는 마이크 신호를 재생하지 않으므로 하울링 루프에 포함하지 않고, 마이크에 섞이는 악기 소리(유입)만 계산합니다. 마이크를 FRFR 등으로도 보내면 해당 스피커의 "보컬 신호 출력"을 켜세요.

    실내 전달: 직접음 + 이미지 소스법 2차 반사(위상 포함, 반사가 일어나는 벽 위 실제 지점의 재질·흡음재 반영) + 확산 잔향(Eyring 잔향시간, 실정수 R, 피크 계수 +6 dB).

    마이크: Shure Beta 58A는 슈퍼카디오이드(감도 최저점 약 126°)와 4–6 kHz 프레즌스 상승, 저역 롤오프를 반영합니다. 스피커/앰프 제원은 공개 사양 기반의 대략적인 값이므로 실제 모델 사양에 맞게 수정하세요.

    자동 배치: 스피커는 방 둘레(벽)를 따라 움직이는 좌표로 탐색해 항상 벽에 붙습니다. 무작위 탐색 → 다중 시작 국소 탐색 → 정밀 격자 재평가와 위치 오차(±10 cm, ±5°) 강건성 검사.

    흡음재 추천: 각 벽의 스피커→마이크 1차 반사 지점, 벽 중앙, 모서리(베이스트랩), 천장, 바닥 후보를 종류·크기별로 시뮬레이션해 면적 대비 효과가 가장 큰 것부터 고릅니다.

    간이 모델이므로 실제 값과 차이가 있을 수 있습니다. 설치 후 실제로 소리를 내 보며(링아웃) 최종 확인하세요.
