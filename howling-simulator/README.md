# 하울링 시뮬레이터 — 합주실

방의 크기·높이·벽별 재질, 스피커/앰프의 정격 출력(W)·볼륨(%)·좌우 방향·상하 각도, 마이크 위치·방향, 인원 위치를 GUI에서 설정하면
**하울링(음향 피드백) 발생 여부**를 주파수별로 예측하고, **스피커·마이크 자동 배치**와 **흡음재 추천(종류·위치·양)** 을 해 주는 웹 앱입니다.

설치가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다 (모바일 포함).

## 주요 기능

| 기능 | 설명 |
|---|---|
| 방 | 길이·폭·높이, A·B·C·D벽/바닥/천장별 재질 → 잔향시간 RT60(중역·저역) |
| 스피커·앰프 | 모델 프리셋(PA 12/15인치, HeadRush FRFR-112/108, Blackstar ID:Core 10/20/40/100, 베이스 콤보), 출력 W, 감도, 볼륨(노브 %), 위치, **좌우 방향·상하 각도 슬라이더**, "보컬 신호 출력" 여부 |
| 마이크 | **Shure Beta 58A**(슈퍼카디오이드, 감도 최저점 약 126°, 4–6 kHz 프레즌스), SM58, 일반 패턴 |
| 인원 | 기본 6명 (보컬은 마이크를 따라감). 사람 흡음 반영, 각 위치의 PA 보컬 음압 계산 |
| 판정 | 하울링 발생/위험/안정, 최대 루프 게인, 하울링 주파수, PA 하울링 시작 볼륨, 악기 소리 마이크 유입 |
| 지도 | 마이크 위치별 하울링 위험도 / 마이크 위치별 악기 소리 유입 / PA 보컬 음압 분포 |
| 자동 최적 배치 | PA·악기 앰프·마이크 선택 최적화. **스피커는 항상 벽에 붙여 배치**(벽에서 약 20 cm, 상하 각도 포함). 보컬은 멤버들을 바라보도록 |
| 마이크만 최적화 | 스피커는 그대로 두고 마이크 위치·방향만 최적화 |
| 흡음재 추천 | 어떤 흡음재(50/100 mm 패널, 스펀지, 커튼, 베이스트랩, 러그)를 **어느 벽 어디에(가로·높이 범위)** **얼마나(패널 장수·m²)** 붙일지, 이유와 효과(하울링 여유·RT60)까지 제시, 원클릭 적용 |

## 합주실에서 알아둘 점

- **기타·베이스 앰프는 하울링 원인이 아닙니다.** 마이크 신호를 재생하지 않기 때문입니다(앱 기본값: "보컬 신호 출력" 꺼짐).
  대신 보컬 마이크에 악기 소리가 섞이는 양(블리드)을 계산합니다. 블리드가 크면 보컬을 더 키워야 하므로 결국 하울링에 불리합니다.
  FRFR 등으로 마이크 신호도 보내는 경우 해당 스피커의 "보컬 신호 출력"을 켜세요.
- Beta 58A 같은 슈퍼카디오이드는 정후면(180°)보다 **약 126° 방향**이 가장 둔감합니다. PA 2대를 마이크 뒤쪽 양옆에 두는 것이 유리합니다.
- 작은 방에서는 중저역(200–400 Hz) 잔향이 하울링 한계를 정하는 경우가 많습니다. 이때는 배치보다 흡음·볼륨·EQ가 효과적이며, 앱이 이를 진단해 알려 줍니다.

## 계산 모델

- **루프 게인** = 전기적 게인 + 실내 전달(보컬 스피커 → 마이크). 0 dB 이상이면 하울링, 기본 6 dB 이상 여유를 "안정"으로 판정.
- **전기적 게인**: 스피커 1 m 음압 = 감도 + 10·log₁₀(W) + 볼륨 노브 게인. 볼륨 노브는 기본 **오디오(로그) 테이퍼**(50% ≈ −21 dB, 선형도 선택 가능).
  마이크 기준 입력(기본 100 dB SPL)으로 노래할 때 볼륨 100%에서 정격 출력이 나오도록 믹서 게인이 맞춰져 있다고 가정(고급 설정).
- **초기음**: 직접음 + 이미지 소스법 2차 반사까지 위상 포함 합산. 반사가 일어나는 **벽 위의 실제 지점**을 계산해 그 지점의 재질/흡음재 흡음률을 적용
  (그래서 흡음재 "위치"가 결과에 반영됨).
- **후기 잔향**: Eyring 잔향시간, 실정수 R, 마이크 랜덤 에너지 효율, 잔향 음장 피크 계수 +6 dB.
- **자동 배치**: 스피커 위치를 방 둘레(벽) 좌표로 탐색 → 무작위 탐색 + 다중 시작 국소 탐색 + 정밀 재평가 + 위치 오차(±10 cm, ±5°) 강건성 검사.
  멤버·스피커와 겹치는 배치에는 벌점.
- **흡음재 추천**: 각 표면의 스피커→마이크 1차 반사 지점, 벽 중앙, 모서리, 천장, 바닥 후보를 종류·크기별로 시뮬레이션해
  하울링 여유와 합주실 권장 잔향시간(0.3–0.45초)을 면적 대비 가장 많이 개선하는 것부터 단계적으로 선택.

> 간이 물리 모델이며, 스피커/앰프 제원은 공개 사양 기반의 대략적인 값입니다. 실제 모델 사양에 맞게 수정하고, 설치 후 링아웃으로 최종 확인하세요.
