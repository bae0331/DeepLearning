# 하울링 시뮬레이터 (Acoustic Feedback Simulator)

방의 크기·높이·마감재, 스피커의 정격 출력(W)·볼륨(%)·방향, 마이크의 위치·방향·지향성을 GUI에서 설정하면
**하울링(음향 피드백) 발생 여부**를 주파수별로 예측하고, **스피커·마이크의 최적 배치**를 자동으로 찾아주는 웹 앱입니다.

설치가 필요 없습니다. `index.html`을 브라우저(Chrome, Edge, Safari 등)로 열면 바로 동작합니다. 모바일에서도 사용할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 방 설정 | 길이·폭·높이, 무대 깊이, 청중 수, 벽/바닥/천장 재질(12종) → 잔향시간 RT60 자동 계산 |
| 스피커 | 타입(박스형·혼·광지향·천장 매립·무지향), 정격 출력 W, 감도, 볼륨 %, 위치 X/Y/Z, 수평 방향, 기울기 (여러 대) |
| 마이크 | 지향성(무지향·카디오이드·슈퍼/하이퍼카디오이드), 위치, 방향, 기울기 (여러 개) |
| 평면도·측면도 | 드래그로 이동, 점(●) 핸들로 방향/기울기 회전 (Shift: 15° 단위) |
| 판정 | 하울링 발생 / 위험(여유 부족) / 안정, 최대 루프 게인, 하울링 예상 주파수, 하울링 시작 볼륨 |
| 주파수 그래프 | 63 Hz–8 kHz 루프 게인 곡선 (잔향 성분 별도 표시, 마우스 오버로 값 확인) |
| 지도 | 마이크 위치별 하울링 위험도 히트맵, 객석 음압 분포 히트맵 |
| 진단 | 주 원인 경로, 마이크/스피커 방향 문제, 잔향 지배 여부, EQ 컷 주파수, 권장 볼륨(원클릭 적용) |
| 자동 최적 배치 | 하울링 안정 여유 + 객석 커버리지를 함께 최적화, 되돌리기 지원 |
| 저장 | 브라우저 자동 저장, JSON 파일로 저장/불러오기 |

## 계산 모델

- **루프 게인(dB)** = 전기적 게인 + 실내 전달(스피커 → 마이크). 어느 주파수에서든 0 dB 이상이면 하울링.
  실무 기준에 따라 기본 6 dB 이상의 여유를 "안정"으로 판정합니다.
- **전기적 게인**: 스피커 1 m 음압 = 감도 + 10·log₁₀(정격 W) + 20·log₁₀(볼륨/100).
  마이크에 *기준 입력 음압*(기본 105 dB SPL, 고급 설정)이 들어올 때 볼륨 100%에서 정격 출력이 나오도록 게인 구조가 맞춰져 있다고 가정합니다.
- **초기음**: 직접음 + 이미지 소스법(Allen–Berkley) 2차 반사까지 위상을 포함해 합산 → 콤 필터 피크 재현.
  옥타브 밴드 흡음률, 공기 흡음, 스피커 HPF, 마이크 채널 로우컷(기본 100 Hz) 반영.
- **후기 잔향**: Eyring 잔향시간과 실정수 R로 확산음장 에너지 16π/(Q·R) 계산, 마이크 랜덤 에너지 효율(REE) 적용,
  잔향 음장의 주파수 응답 피크를 고려해 +6 dB.
- **지향성**: 스피커는 주파수에 따라 좁아지는 지향 계수 Q 모델 `((1+cosθ)/2)^(Q−1)`, 마이크는 `a + (1−a)·cosφ` 극성 패턴.
- **최적화**: 무작위 탐색 500회 → 다중 시작 국소 탐색 6×220회 → 정밀 주파수 격자(1/48 옥타브) 재평가 +
  위치 오차(±10 cm, ±5°) 강건성 검사. 마이크는 무대 영역 안(화자가 객석을 향하도록 ±45°),
  스피커는 "무대 앞쪽·객석 방향"(기본) 또는 "방 전체" 영역에서 탐색합니다.

> 간이 물리 모델이므로 실제 현장과 차이가 있을 수 있습니다. 설치 후에는 실측과 링아웃(EQ 조정)으로 최종 확인하세요.

## 파일 구성

```
howling-simulator/
├── index.html            # GUI
├── style.css
├── app.js                # 화면·상호작용·최적화 실행
├── acoustics.js          # 음향 계산 엔진 (브라우저/Node 공용)
└── test/acoustics.test.js
```

## 테스트

```bash
node --test howling-simulator/test/acoustics.test.js
```
